# 🎮 RetroArcade

**RetroArcade** is a simple Android game application that brings several classic arcade-style games together in one app.

The project was developed using **Android Studio** as a learning project to explore mobile application development, game logic, user interface design, and interactive gameplay.

## ✨ Features

* 🎮 Multiple classic games in one application
* 🏠 Simple and easy-to-use home screen
* 🕹️ Classic arcade-style gameplay
* 📱 Designed for Android devices
* 👨‍💻 Developer information page
* 🔄 Ability to navigate between different games
* 🎯 Simple controls and gameplay mechanics

## 🕹️ Games

RetroArcade includes a collection of classic games, including:

* 🐍 **Snake**
* 🧱 **Tetris**
* 🏓 **Pong**
* ❌⭕ **Tic-Tac-Toe**
* 🃏 **Memory**
* 🎮 Other classic-style games coming soon

More games can be added to the application in the future.

## 🚀 Getting Started

### Requirements

Before running the project, make sure you have:

* Android Studio installed
* Android SDK installed
* An Android emulator or physical Android device
* Internet connection for Gradle dependencies during the first build

### Installation

1. Clone the repository:

```bash
git clone https://github.com/HamdanGitHub/RetroArcade.git
```

2. Open **Android Studio**.

3. Select:

```text
File → Open
```

4. Select the downloaded **RetroArcade** project.

5. Allow Gradle to sync and download the required dependencies.

6. Connect an Android phone with **USB Debugging** enabled, or start an Android Emulator.

7. Click **Run ▶** in Android Studio.

The application should then be installed and launched on the selected Android device.
